Vector databases are specialized databases designed to store and search high-dimensional numerical vectors.

Vectors are commonly generated by machine learning models called embedding models. These embeddings represent the semantic meaning of text, images, audio, or other data.

Semantic search works by converting a query into a vector and comparing it against stored vectors using a similarity or distance metric.

HNSW, or Hierarchical Navigable Small World, is an approximate nearest neighbor algorithm. It uses a multilayer graph structure to efficiently find vectors that are close to a query vector.

Retrieval-Augmented Generation, or RAG, combines vector search with a large language model. Relevant documents are first retrieved from a vector database and then provided to the language model as context for generating an answer.
