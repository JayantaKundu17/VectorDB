TOPIC: Data Drift
CATEGORY: data_drift

DEFINITION
Data drift occurs when the distribution of model inputs changes over time.

HOW IT WORKS
It can be detected with summary statistics, divergence measures, classifiers, or domain-specific tests.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.
