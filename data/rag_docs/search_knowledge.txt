TOPIC: Search Algorithms
CATEGORY: search

DEFINITION
AI search algorithms explore a state space to find a path or solution that satisfies a goal.

HOW IT WORKS
Breadth-first search expands shallow nodes first, depth-first search explores deeply, and heuristic methods such as A* use an estimate of remaining cost.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
path planning, puzzle solving, routing, game search
