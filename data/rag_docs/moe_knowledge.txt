TOPIC: Mixture of Experts
CATEGORY: moe

DEFINITION
Mixture-of-Experts models contain multiple expert subnetworks and route each token to a subset of them.

HOW IT WORKS
Sparse routing can increase total parameter capacity without activating every parameter for every token.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
large language models and conditional computation

LIMITATIONS / FAILURE MODES
