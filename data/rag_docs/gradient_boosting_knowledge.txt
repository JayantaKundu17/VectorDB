TOPIC: Gradient Boosting
CATEGORY: gradient_boosting

DEFINITION
Gradient boosting builds an additive model by sequentially fitting weak learners to reduce a loss.

HOW IT WORKS
Each new learner focuses on the current model's errors or negative gradient. Tree-based boosting is common for tabular data.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
tabular prediction, ranking, structured data

ADVANTAGES / STRENGTHS
This approach is useful when its assumptions and inductive biases match the structure of the problem. It can provide a strong baseline, specialized performance, interpretability, efficiency, or scalability depending on the topic.

LIMITATIONS / FAILURE MODES
overfitting with excessive rounds, tuning sensitivity

COMPARISON
Gradient Boosting should be distinguished from random forest. The best choice depends on data size, feature type, dimensionality, latency, accuracy, interpretability, and operational constraints.

EVALUATION / PRACTICAL CHECKS
Choose metrics that match the task and business cost of errors. Validate on a representative holdout or cross-validation design, check leakage, inspect failure cases, and monitor performance after deployment.

INTERVIEW TAKEAWAY
Be prepared to explain what Gradient Boosting is, how it works, when to use it, what assumptions it makes, and what trade-offs or failure modes it has.
