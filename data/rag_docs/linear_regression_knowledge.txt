TOPIC: Linear Regression
CATEGORY: linear_regression

DEFINITION
Linear regression predicts a continuous target as a weighted combination of input features and an intercept.

HOW IT WORKS
Ordinary least squares minimizes the sum of squared residuals. Coefficients describe linear relationships under the model assumptions.

KEY IDEAS
Basic prediction form: y_hat = w^T x + b.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
forecasting continuous values, baselines, interpretable models

ADVANTAGES / STRENGTHS
This approach is useful when its assumptions and inductive biases match the structure of the problem. It can provide a strong baseline, specialized performance, interpretability, efficiency, or scalability depending on the topic.

LIMITATIONS / FAILURE MODES
linearity assumptions, outliers, multicollinearity

COMPARISON
Linear Regression should be distinguished from Ridge and Lasso regression. The best choice depends on data size, feature type, dimensionality, latency, accuracy, interpretability, and operational constraints.

EVALUATION / PRACTICAL CHECKS
Choose metrics that match the task and business cost of errors. Validate on a representative holdout or cross-validation design, check leakage, inspect failure cases, and monitor performance after deployment.

INTERVIEW TAKEAWAY
Be prepared to explain what Linear Regression is, how it works, when to use it, what assumptions it makes, and what trade-offs or failure modes it has.
