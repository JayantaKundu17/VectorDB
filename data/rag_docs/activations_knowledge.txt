TOPIC: Activation Functions
CATEGORY: activations

DEFINITION
Activation functions introduce nonlinearity into neural networks.

HOW IT WORKS
Common choices include ReLU, sigmoid, tanh, GELU, and softmax. Different activations have different gradient and range properties.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
neural-network hidden layers and output layers
