TOPIC: LoRA
CATEGORY: lora

DEFINITION
LoRA adapts a pretrained model by learning low-rank updates instead of updating all base parameters.

HOW IT WORKS
The base weights can remain frozen while small trainable matrices represent the adaptation.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
parameter-efficient fine-tuning
