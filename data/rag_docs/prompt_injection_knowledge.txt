TOPIC: Prompt Injection
CATEGORY: prompt_injection

DEFINITION
Prompt injection is an attack where untrusted text attempts to manipulate a model into ignoring intended instructions or performing unsafe actions.

HOW IT WORKS
Defense should use strict trust boundaries, tool permissions, input/output validation, and separation between instructions and data.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
