TOPIC: Context Windows
CATEGORY: context_window

DEFINITION
A context window is the amount of tokenized information a model can attend to or otherwise process in one request.

HOW IT WORKS
Longer contexts can hold more documents or conversation history but increase cost and can dilute attention over irrelevant information.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
long-document QA, agents, RAG

LIMITATIONS / FAILURE MODES
