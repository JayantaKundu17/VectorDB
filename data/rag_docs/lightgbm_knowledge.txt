TOPIC: LightGBM
CATEGORY: lightgbm

DEFINITION
LightGBM is a gradient-boosted tree framework optimized for speed and memory efficiency on large tabular datasets.

HOW IT WORKS
It uses histogram-based learning and leaf-wise tree growth with constraints to control complexity.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
large tabular datasets and fast boosting

LIMITATIONS / FAILURE MODES
