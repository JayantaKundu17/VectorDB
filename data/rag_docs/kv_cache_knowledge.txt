TOPIC: KV Cache
CATEGORY: kv_cache

DEFINITION
A key-value cache stores attention keys and values from previous generated tokens so they do not need to be recomputed during autoregressive decoding.

HOW IT WORKS
Caching improves generation efficiency but consumes memory that grows with sequence length, layers, and batch size.
