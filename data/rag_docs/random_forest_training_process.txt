TOPIC: Random Forest Training Process

CATEGORY: random_forest, decision_trees, ensemble_learning

WHAT IS RANDOM FOREST?

Random Forest is an ensemble machine learning algorithm that combines multiple decision trees to improve predictive performance and generalization. It uses bootstrap sampling and random feature selection to create diversity among trees.

STEP 1: CREATE BOOTSTRAP SAMPLES

Given a training dataset with N examples, create a separate training sample for each tree by sampling N examples with replacement. Because sampling is performed with replacement, some examples may appear multiple times and some may not appear in a particular tree's sample.

STEP 2: START BUILDING EACH TREE

Train a decision tree on each bootstrap sample. Unlike gradient boosting, Random Forest generally trains its trees independently, so the trees do not need to wait for previous trees to finish.

STEP 3: SELECT RANDOM FEATURES AT EACH SPLIT

When deciding how to split a node, consider only a randomly selected subset of the available features rather than all features. Select the best split among those candidate features according to the tree's splitting criterion.

Random feature selection reduces similarity between trees and helps prevent a small number of strong features from dominating every tree.

STEP 4: CHOOSE THE BEST SPLIT

For classification, a tree may use Gini impurity or entropy to measure the quality of a split. For regression, it may use variance reduction or squared-error-based criteria.

The tree chooses a split that improves the selected criterion, then recursively partitions the data into smaller groups.

STEP 5: GROW THE TREE

Repeat feature selection and splitting until a stopping condition is reached. Conditions may include a maximum depth, minimum samples required to split a node, minimum samples in a leaf, or another configured limit.

Repeat the tree-building procedure for each bootstrap sample to create the forest.

STEP 6: GENERATE PREDICTIONS

Pass a new input through every trained tree. Each tree independently produces a prediction.

For classification, Random Forest commonly combines tree predictions using majority voting, or averages class probabilities when configured to do so.

For regression, Random Forest commonly averages the numerical predictions from its trees.

STEP 7: IMPROVE GENERALIZATION

Bootstrap sampling and random feature selection introduce diversity among trees. Aggregating diverse trees can reduce prediction variance and help generalization compared with relying on a single decision tree.

The benefit depends on the dataset, feature relationships, tree settings, and number of trees.

OUT-OF-BAG EVALUATION

Because bootstrap sampling leaves some training examples out of a particular tree's sample, those examples can serve as out-of-bag observations for that tree. Predictions from trees for which an observation was out of bag can be combined to estimate out-of-bag performance. This provides a useful evaluation estimate without requiring a separate validation prediction from every tree.

IMPORTANT HYPERPARAMETERS

The number of trees controls the size of the ensemble. The maximum tree depth and minimum samples per split or leaf control tree complexity. The number of candidate features considered at each split influences tree diversity. Bootstrap settings determine how training samples are generated.

RANDOM FOREST VS XGBOOST

Random Forest generally builds trees independently and combines their predictions through voting or averaging. XGBoost builds trees sequentially, with each new tree improving the current ensemble according to loss gradients and the regularized objective.

Random Forest primarily relies on bagging and feature randomness to reduce correlation among trees. XGBoost uses sequential boosting, learning-rate shrinkage, regularization, and optional subsampling to optimize predictive performance.

ADVANTAGES

Random Forest can model nonlinear relationships and feature interactions, requires relatively little feature scaling, and often provides a strong baseline. Averaging or voting across diverse trees can improve stability compared with one unrestricted decision tree.

LIMITATIONS

Random Forest can require substantial memory and prediction time when it contains many large trees. It is less interpretable than a single decision tree, and its performance still depends on suitable data and hyperparameters. It does not guarantee that overfitting will never occur.

SUMMARY

Random Forest creates bootstrap samples, trains decision trees independently, selects random subsets of features at each split, and combines their predictions. Classification commonly uses majority voting, while regression commonly uses averaging. Bootstrap sampling and random feature selection help create diverse trees and improve generalization.
