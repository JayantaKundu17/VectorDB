TOPIC: Bi-Encoders
CATEGORY: bi_encoder

DEFINITION
A bi-encoder separately embeds queries and documents so vectors can be compared efficiently.

HOW IT WORKS
Independent encodings enable large-scale vector indexing and retrieval, while sacrificing some pairwise interaction.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
dense retrieval, semantic search

ADVANTAGES / STRENGTHS
This approach is useful when its assumptions and inductive biases match the structure of the problem. It can provide a strong baseline, specialized performance, interpretability, efficiency, or scalability depending on the topic.

LIMITATIONS / FAILURE MODES
embedding quality and domain mismatch

Bi-Encoders should be distinguished from closely related approaches in the same problem family. The best choice depends on data size, feature type, dimensionality, latency, accuracy, interpretability, and operational constraints.
