TOPIC: Vector Databases
CATEGORY: vector_databases

DEFINITION
A vector database stores vectors and supports nearest-neighbor or similarity search, often alongside metadata or source text.

HOW IT WORKS
ANN indexes such as HNSW make retrieval practical for larger vector collections.

KEY IDEAS
The exact implementation depends on the model family, data type, objective, and operating constraints.
The main design variables are representation, objective function, optimization or search procedure, and evaluation criteria.

COMMON USE CASES
semantic search, RAG, recommendation, multimodal retrieval

LIMITATIONS / FAILURE MODES
